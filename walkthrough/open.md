# Open an EDI file

EDI files open as text first. To see the tree:

- Click the tree icon at the top right of the text editor, or
- right-click the file in the Explorer and pick Open in EDI Viewer, or
- run EDI Viewer: Open in EDI Viewer from the Command Palette.

The Tree tab shows interchanges, functional groups, transaction sets (or messages), loops and segments. Click a segment to see each element with its name, value and code meaning. Double-click to select it in the text.
