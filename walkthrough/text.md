# Names on hover

Files ending in .edi, .x12, .edifact, .850, .837 and similar open in the text editor with colours for segment IDs and separators.

- Rest the mouse on a value: you see the element ID (for example CLM01), its name and, for codes, what the code means.
- Format EDI (one segment per line) and Minify EDI (one line) are in the right-click menu. Only the white space between segments changes.
